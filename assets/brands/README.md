# Brand marks

This folder contains self-hosted original-color technology SVG marks used by the portfolio. Azure, Azure DevOps, Terraform, Ansible, and Kubernetes SVGs were extracted from Devicon 2.18.0 (`devicon.dev`, https://github.com/devicons/devicon). Font Awesome brand glyphs are used for AWS, Docker, Linux, WordPress, and social networks.

Company and product marks remain trademarks of their respective owners. The marks are included only to identify tools and services used in the portfolio.
